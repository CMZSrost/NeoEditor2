## 调试工具（R38）：剪贴板接管 · F12 DevTools · 日志目录/导出 · 报错捕捉

### 1. 剪贴板完全接管（host.html v2.53）— 不再弹权限窗、不再写真实剪贴板
现状：writeText wrapper 拦截后仍用隐藏 textarea + `execCommand('copy')` 写真实剪贴板（→"剪贴板里一堆东西"+ 每次启动的"允许写入剪贴板"弹窗）；readText 800ms 轮询还会弹读取权限框。已确认 Ruffle 只调 `writeText`（ruffle.js/core 无 ClipboardItem）。

- `navigator.clipboard.writeText` → 只 `captureClipboard(text)` 进日志（level=clipboard → /__log），返回 `Promise.resolve()`，不再 execCommand、不写真实剪贴板
- `navigator.clipboard.readText` → 返回 `Promise.resolve("")`（游戏无真实读需求；避免读权限弹窗）
- **删除** `grantClipboardAccess` + 800ms readText 轮询（不再读用户真实剪贴板，隐私也更干净）
- 结果：启动零弹窗、真实剪贴板干净、内容全部进日志/日志文件

### 2. F12 开发者工具（Chromium DevTools：Network + Application/localStorage + Console）
- `TryOpenDevTools()`：`_webView.TryGetPlatformHandle()` → `IWindowsWebView2PlatformHandle.CoreWebView`（原始 ICoreWebView2）→ `SetAreDevToolsEnabled(true)` + `OpenDevToolsWindow()`；全程 try/catch，失败时状态栏提示"开发者工具不可用"
- 触发：窗口 KeyDown 加 F12（现有 F11 同处）+ 新"调试"菜单项（HotKey=F12）
- 实现时先用反射脚本核对包内成员名（plan 模式禁 powershell，实现阶段允许）；若 interop 缺方法则降级：仅尝试 OpenDevToolsWindow

### 3. 打开日志目录 / 导出日志
- **LogOverlayWindow 顶栏**加两个按钮（+ 主窗口"调试"菜单同步提供）：
  - 打开日志目录：`explorer.exe /select,"最新 player-run-*.log"`（无文件则打开目录）— 用 `FileLogDirectory`（已在 VM 上）
  - 导出日志：新 `PlayerViewModel.ExportLogsCommand` → 生成 `player-log-export-{时间戳}.txt` 写入日志目录（头部信息 + 全部 run 日志行 + localStorage 快照），完成后自动 explorer /select 打开；状态栏显示导出路径
- localStorage 快照：host.html 暴露 `window.__dumpLocalStorage()`（key/长度/前 200 字符预览）；VM 加可注入 `ExecuteJs`（PlayerWindow.AttachViewModel 里接线，复用 StorageManager 的 InvokeScript 模式），导出时调用
- 报告构建放 Core 新类 `RunLogReport.Build(...)`（纯函数，可测试）

### 4. 游戏报错捕捉（AVM 崩溃 → 播放器弹窗 + 日志）
本版 Ruffle 不派发 error 事件（已核实仅有 loadedmetadata/loadeddata），运行时 AVM 错误走 console.error 通道（已转发进日志）。补全：
- host.html：`window.__log = send` 全局暴露；加 `unhandledrejection` 监听；`load().catch` 额外 `__log("error", ...)`（原来只在页面内 overlay）
- SwfLogBridge：新增 `PlayerGameEventType.GameError` + 致命签名正则（window.onerror / unhandledrejection / cannot convert / TypeError / ReferenceError / RangeError / stack overflow / Maximum call stack / SWF 加载失败），复用 10s 去抖 → 事件上抛
- PlayerViewModel：GameError → 状态栏"⚠ 检测到游戏错误"+ 新事件 `GameErrorDetected(detail)`（每 run 只弹一次）；GameExit 时若本 run 有 error 级行 → 状态栏"游戏异常退出"
- PlayerWindow：弹 `PromptDialogWindow`：标题"检测到游戏错误"，正文 = 错误信息（截断 300 字）+ 提示已入日志，按钮 [打开日志目录] [知道了]（confirm→打开日志目录）
