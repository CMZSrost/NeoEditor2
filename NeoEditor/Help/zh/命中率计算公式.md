# 命中率计算公式详解

本文档基于 Neo Scavenger 原版 `CheckAttack` 函数反编译代码，详细解析命中率判定的完整流程。

---

## 一、命中判定总览

攻击命中判定分为三个阶段：
1. **偷袭判定**（必定命中）
2. **正面对抗判定**（概率计算）
3. **保底判定**（最低 5%）

---

## 二、偷袭判定（必定命中）

以下两种情况攻击**必定命中**，直接进入伤害结算：

### 情况 1：目标处于睡眠状态

```
目标正在睡眠（Asleep = true）
且 随机数 > 目标警戒值（m_fSleepAwareness）
→ 必定命中
```

- 目标拥有固定的睡眠警戒值
- 系统为你分配一个随机数
- 如果你的随机数大于目标警戒值，攻击成功

### 情况 2：目标未发现攻击者

```
目标没有发现攻击者（UsSpotted = false）
→ 必定命中
```

**注意**：偷袭失败后会进入正常的正面对抗判定流程，而非直接失败。

---

## 三、正面对抗判定

### 基本变量

| 变量 | 说明 | 来源 |
|------|------|------|
| 基础命中率 | 从 `100%` 开始 | 固定值 |
| 敌方防御值 `m_fDefense` | 直接降低命中率 | `conditions` 状态系统 |
| 可见性调整 `fAdjVisibility` | 光照/环境修正 | Hex 地块 + 自身状态 |
| 攻击系数 `fCoeff` | 技能/武器系数 | BattleMove 传入 |

### 可见性调整公式

\\[
\text{fAdjVisibility} = \text{当前地块光照等级} + \text{目标自身亮度} - \text{攻击者最小适应亮度}
\\]

其中：
- **地块光照等级** `m_vLightLevels[nTimeOfDay]`：每天 6 个时段的光照（凌晨/上午/中午/下午/傍晚/半夜）
- **目标自身亮度** `LightLevel`：来自 `conditions` 状态
- **最小适应亮度** `MinLightLevel`：攻击者的夜视能力

---

## 四、近战攻击公式

\\[
\text{命中概率} = \left[ (1.0 - \text{敌方防御值}) + 0.25 \times \text{可见性调整} \right] \times \text{攻击系数}
\\]

若计算结果 < 5%，则取 **5%**（最低保底）。

### 示例

| 参数 | 值 | 说明 |
|------|-----|------|
| 敌方防御值 | 0.2 | 20% 闪避 |
| 可见性调整 | 0.3 | 较亮环境 |
| 攻击系数 | 1.0 | 无特殊修正 |

\\[
\text{命中率} = \left[ (1.0 - 0.2) + 0.25 \times 0.3 \right] \times 1.0 = (0.8 + 0.075) = 0.875 = 87.5\%
\\]

## 五、远程攻击公式

远程攻击比近战多出几个修正因子：

### 射程系数

\\[
\text{fRangeFactor} = \frac{\text{EffectiveRange}()}{\text{攻击模式射程} + 1}
\\]

- **EffectiveRange()**：实际交火距离
- **近距（贴脸）**：射程系数接近 0
- **最大射程 +1**：射程系数 = 1（最远有效射程）

### 降雨惩罚

```
如果正在下雨（bPrecip = true）：
    命中率 -= fRangeFactor × 0.15
```

雨水惩罚随距离增加而增大。

### 距离衰减

\\[
\text{命中率} \mathrel{*}= (1 - \text{fRangeFactor})
\\]

近距离时衰减最小，最远射程时命中率降至 0%。

### 掩体影响

\\[
\text{命中率} \mathrel{*}= (1 - \text{目标掩体值 } m\_fCover)
\\]

---

### 远程完整公式

\\[
\begin{aligned}
\text{命中概率} = &\left[ (1.0 - \text{敌方防御值}) \right. \\
&+ \left. \text{可见性调整} \times \text{射程系数} \right. \\
&- \left. \text{降雨惩罚} \times \text{射程系数} \right] \\
&\times (1 - \text{射程系数}) \\
&\times (1 - \text{掩体影响}) \\
&\times \text{攻击系数}
\end{aligned}
\\]

## 六、原版代码参考

```actionscript
public function CheckAttack(nType:Int, fCoeff:Float):Bool
{
    var bSuccess:Bool = false;
    
    // 1. 偷袭判定
    if (sprThem.Asleep && Math.random() > sprThem.m_fSleepAwareness) 
    {
        bSuccess = true;
    }
    else if (UsSpotted == false) 
    {
        bSuccess = true;
    }
    else 
    {
        // 2. 正面对抗
        var fChance:Float = 1.0;           // 从100%开始
        fChance -= sprThem.m_fDefense;     // 减去敌方防御
        
        // 可见性调整
        var fAdjVisibility:Float = 
            sprThem.m_tilCurrentHex.m_vLightLevels[PlayState.m_objInstance.nTimeOfDay] 
            + sprThem.LightLevel 
            - sprUs.MinLightLevel;
        
        if (nType == AttackMode.ATTACK_TYPE_MELEE) 
        {
            // 近战
            fChance += fAdjVisibility * 0.25;
        }
        else 
        {
            // 远程
            var nAModeRange:Int = sprUs.CurrentAttackMode.m_nRange;
            if (nAModeRange == 0) nAModeRange = 2;
            
            var fRangeFactor:Float = EffectiveRange() / (nAModeRange + 1);
            
            if (PlayState.m_objInstance.grpWeatherNode.objWeatherLast.bPrecip) 
                fChance -= fRangeFactor * 0.15;   // 降雨惩罚
            
            fChance += fAdjVisibility * fRangeFactor;  // 光照
            fChance *= 1 - fRangeFactor;               // 距离衰减
            fChance *= 1 - sprThem.m_fCover;           // 掩体
        }
        
        fChance *= fCoeff;
        
        // 3. 最低 5% 保底
        if (fChance < 0.05) fChance = 0.05;
        if (Math.random() <= fChance) bSuccess = true;
    }
    
    return bSuccess;
}
```

## 七、Mod 修改思路

### 提高命中率的方法

| 方法 | 难度 | 效果 |
|------|:--:|------|
| **修改武器射程** (`nRange`) | 简单 | 提高射程系数，间接提高远程命中率，但影响有限 |
| **降低敌方防御值** (`m_fDefense`) | 中等 | 最有效的手段，可通过修改震慑技能实现 |
| **提高光照等级** (`LightLevel`) | 中等 | 增加可见性调整值，可为自己添加状态提高此值 |
| **提高震慑技能发动概率** | 中等 | 降低敌方防御值，近战远程通用 |
| **降低敌方掩体值** (`m_fCover`) | 中等 | 减少掩体惩罚 |
| **修改基础命中率** | 困难 | 需要修改核心代码 |

### 注意事项

- 光照等级过高可能导致敌人更容易惊醒，偷袭成功率降低
- 射程系数的影响是有限的（因为 `fChance *= 1 - fRangeFactor` 在远程公式中的作用更大）
- 最低命中率 5% 是硬编码的，无法通过修改 XML 数据改变

## 八、相关数据字段

| 数据表 | 字段 | 说明 |
|--------|------|------|
| `battlemoves` | `nAttackModeType` | -1=非攻击，0=近战，1=远程 |
| `battlemoves` | `fChance` | 可使用该动作的概率 |
| `battlemoves` | `fDetect` | 被发现几率 |
| `battlemoves` | `nMinRange` / `nMaxRange` | 距离要求，-1=全场 |
| `attackmodes` | `nRange` | 攻击距离 |
| `conditions` | `m_fDefense` | 防御/闪避值 |
| `conditions` | `LightLevel` | 光照等级 |
| `conditions` | `MinLightLevel` | 最小适应亮度（夜视） |
| `conditions` | `m_fSleepAwareness` | 睡眠警戒值 |
| `hextypes` | `vLightLevels` | 地块各时段光照 |
| `creatures` | `m_fCover` | 掩体值 |
