# 快速入门

## 1. 首次设置

打开 NeoEditor 后，首先需要设置 **游戏根目录**（Neo Scavenger 的安装目录）：

1. 点击左侧 ⚙️ **Settings**
2. 在 **Game Root Directory** 中输入路径，或点击 Browse 浏览选择
3. 例如：`D:\Steam\steamapps\common\Neo Scavenger`

设置后，编辑器会自动识别游戏的基础数据和已安装的 Mod。

---

## 2. 导入 Mod

有三种方式导入 Mod：

- **拖拽导入**：直接拖动 Mod 文件夹到编辑器窗口
- **点击导入**：点击工具栏 📥 **Import** 按钮
- **主页导入**：在欢迎页点击 **Import Mod** 卡片

导入的 Mod 会被解析到本地数据库（`game.db`），之后编辑操作都在数据库中完成。

---

## 3. 打开 Mod 编辑

在 **🗄️ Mod Database** 面板中：
- 右键 Mod → **Show Data** 打开编辑视图
- 每个游戏数据类型占一个标签页（ItemType、Recipe、Creature 等）

---

## 4. 编辑数据

### 单元格编辑
- **双击** 单元格进入编辑模式
- `bool` 字段自动显示为 CheckBox
- `Enum` 字段显示为下拉框
- 引用字段（青色下划线）双击可下拉选择目标实体

### 新增行
- 点击工具栏 **+** 按钮
- 选择目标 Mod 和 XML 文件
- 新行 ID 自动递增

### 删除行
- 选中行 → 点击工具栏 **-** 按钮

### 克隆行
- 右键行 → **Clone Row**
- 自动拷贝所有字段，ID 自增

---

## 5. 保存

- `Ctrl+S` 保存当前编辑到数据库 + XML
- 编辑器会显示脏标记（标签页头 **●**）
- 关闭有未保存修改的标签页时会弹出确认提示

---

## 6. 导出

在 **🗄️ Mod Database** 面板右键 Mod → 选择导出格式：
- **CSV**：适合 Excel 编辑
- **XLSX**：全 24 表导出，每表一个 Sheet
- **合成表**：配方→材料→来源的完整链条
- **物品百科**：Markdown 格式物品说明
- **战利品表**：JSON 格式递归展开
