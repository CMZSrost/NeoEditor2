## 1. 攻击类别 (attackmodes)

定义所有武器和攻击方式的属性，包括伤害、射程、音效等。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 代码标号，唯一标识每种攻击方式 |
| `strName` | string | 物品/攻击名称，如"拳头"、".308步枪" |
| `strNotes` | string | 注释，一般留空，对游戏无影响 |
| `nRange` | int | 攻击距离，近战为 1 |
| `fDamageCut` | float | 切割伤害值 |
| `fDamageBlunt` | float | 钝器伤害值 |
| `strChargeProfiles` | string | 弹药/内容物的代码标号，结合 `chargeprofiles` 使用 |
| `nPenetration` | int | 穿透等级 |
| `nType` | int | 攻击类别：0=近战，1=远程 |
| `strSnd` | string | 武器分类声音/动画 |
| `bTransfer` | bool | 弹药位置转移：0=不转移，1=转移（弓箭/弹弓弹药留在敌人身上或掉落） |
| `vAttackerConditions` | string | 攻击时的状态，结合 `conditions` 使用 |
| `strIMG` | string | 右下角武器图标文件名 |
| `fMorale` | float | 该武器默认为你带来的士气补正 |
| `strWieldPhrase` | string | 使用该武器进入战斗时的文字表达 |
| `vAttackPhrases` | string | 攻击时的文字描述，多个用逗号分隔 |

### 武器分类 (strSnd)

| 值 | 分类 |
|----|------|
| `cuePunch` | 近战/拳头 |
| `cueClaws` | 爪子 |
| `cueClub` | 棍棒类（挥舞攻击） |
| `cueBlade` | 利刃 |
| `cueRifle` | 长枪 |
| `cuePistol` | 短枪 |
| `cueLaser` | 激光 |
| `cueBow` | 弓箭类 |
| `cueThrow` | 投掷 |
| `cueChoke` | 勒死（仅杀人头套） |
| `cueGrasp` | 抓住（仅怨灵） |
| `cueBite` | 撕咬（仅野狗） |

## 2. 交易区块 (barterhexes)

定义地图上可交易的商店位置。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 代码标号 |
| `nX` | int | X 轴坐标 |
| `nY` | int | Y 轴坐标 |
| `bBuys` | bool | 是否可以购买玩家的物品（0=不可） |
| `nRestockTreasureID` | int | 引用的战利品数据，结合 `treasuretable` 使用 |

### 特殊案例：底特律 C 商店

底特律 C 商店使用战利品池 `3`（空白地面），因为 C 商店通过剧情（代码 1227）将商品直接生成在玩家脚下（位于底特律高墙内，玩家无法正常走格子进入）。

## 3. 战斗动作 (battlemoves)

定义所有可在战斗中使用的动作，包括攻击、防御、移动等。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 代码标号 |
| `strID` | string | 物品标号，如 "90.35" |
| `strName` | string | 动作名称 |
| `strNotes` | string | 动作注释 |
| `strSuccess` | string | 执行成功时显示的文本（`<us>`=自己，`<them>`=目标） |
| `strFail` | string | 执行失败时显示的文本 |
| `strPopUp` | string | 游戏内动作说明 |
| `vChanceType` | string | 未知，格式 `0,0,0` |
| `vUsConditions` | string | 将为你添加的状态，格式 `[ID,参数1,参数2]` |
| `vThemConditions` | string | 将为敌方添加的状态 |
| `vPairConditions` | string | 将对你产生的影响 |
| `vUsFailConditions` | string | 失败时会为你添加的状态 |
| `vThemFailConditions` | string | 失败时会为敌方添加的状态（**官方全部留空**） |
| `vPairFailConditions` | string | 失败时对你产生的影响 |
| `vUsPreConditions` | string | 前置条件，负数=不可拥有该状态 |
| `vThemPreConditions` | string | 敌方需要满足的前置条件 |
| `nSeeThem` | int | 对方的暴露等级 |
| `nSeeUs` | int | 自己的暴露等级 |
| `bAllOutOfRange` | bool | 离开所有场上目标距离 |
| `bInAttackRange` | bool | 攻击范围（可能用于判定溅射或近战距离） |
| `nMinCharges` | int | 攻击次数（存疑） |
| `nMinRange` | int | 最小距离要求，-1=全场覆盖 |
| `nMaxRange` | int | 最大距离要求，-1=全场覆盖 |
| `nAttackModeType` | int | -1=非攻击，0=近战，1=远程 |
| `vHexTypes` | string | 所需地图格子类型（**官方全部留空**） |
| `fChance` | float | 可使用该动作的概率（百分比） |
| `fPriority` | float | 优先级（BOT 专用，对玩家无效） |
| `fDetect` | float | 执行该动作使你被发现的几率（设为 0 则永远不会被发现） |
| `fOrder` | float | 未知 |
| `fFatigue` | float | 疲劳值消耗 |
| `bApproach` | bool | 该动作是否会使你接近对方 |
| `bOffense` | bool | 是否是攻击性动作 |
| `bFallBack` | bool | 该动作是否为远离动作 |
| `bRetreat` | bool | 该动作是否为撤退动作 |
| `bPosition` | bool | 该动作是否为姿势动作 |
| `bPassive` | bool | 该动作是否为被动 |

## 4. 营地类型 (camptypes)

定义地图上可扎营的位置类型和效果。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 代码标号 |
| `strDesc` | string | 营地描述 |
| `vImageList` | string | 调用的图片 |
| `aCapacities` | string | 营地大小，如 "34x26" |
| `nTreasureID` | int | 战利品池 |
| `m_fAlertness` | float | 默认警戒值 |
| `m_fVisibility` | float | 默认可见值（百分比） |
| `WetTempAdjustMod` | float | 默认温度调节 |
| `m_fHealPerHourMod` | float | 每小时恢复效果 |
| `fSleepQuality` | float | 睡眠质量（百分比，如 -0.26 = -26%） |

> **注意**：所有数值按百分比计算。具体游戏内数值可被睡袋、罐头警报装置、火堆等影响。

## 6. 状态 (conditions)

## 12. 剧情代码 (encounters)

游戏中数据量最大的类别之一，定义所有剧情、对话和事件。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 代码标号 |
| `strName` | string | 剧情名称 |
| `strDesc` | string | 剧情文本（可能很长） |
| `strImg` | string | 调用的图片 |
| `nTreasureID` | int | 生成的战利品池 |
| `nRemoveTreasureID` | int | 移除的战利品池 |
| `aConditions` | string | 附带的剧情状态（结合 `conditions`） |
| `aPreConditions` | string | 前置状态，负数=必须不拥有 |
| `fPrice` | float | 资产变动金额 |
| `aResponses` | string | 玩家回应选项 |
| `aMinimapHexes` | string | 小地图显示点 |
| `bRemoveCreatures` | bool | 是否移除生物 |
| `bRemoveUsed` | bool | 是否移除使用过的物品 |
| `nItemsID` | int | 生成的物品 |
| `nCreatureID` | int | 增加/移除的生物编号 |
| `ptCreatureHex` | string | 生物出现位置，格式 `X,Y` |
| `ptTeleport` | string | 传送位置（0,0=不传送） |
| `ptEditor` | string | 未知 |
| `nType` | int | 0=普通剧情，1=搜刮剧情 |
| `fLootChance` | float | 成功搜刮概率 |
| `fAccidentChance` | float | 意外发生概率 |
| `fCreatureChance` | float | 未知 |
| `vAccidents` | string | 意外事件列表（引用 `encounters`，非 `conditions`） |
| `vLoot` | string | 搜刮成功的战利品 |

### 回应格式 (aResponses)

格式：`=物品IDx数量x0x0x0`

示例：`90.3x1=20x1x0x0x0, 90.4x1=1320x1x0x0x0, =7x1x0x0x0`

- 使用 90.3 号物品 → 触发第 20 号剧情
- 使用 90.4 号物品 → 触发第 1320 号剧情
- 什么都不做 → 触发第 7 号剧情

## 13. 事件触发器 (encountertriggers)

定义剧情在何时、何地、以何种条件触发。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 代码标号 |
| `strName` | string | 触发的剧情名称 |
| `nEncounterID` | int | 触发器的代码标号 |

## 23. 合成表 (recipes)

定义所有物品的合成/制作配方。

| 字段 | 类型 | 说明 |
|------|------|------|
| `nID` | int | 代码标号 |
| `strName` | string | 配方名称 |
| `strSecretName` | string | 隐藏名称（如人肉和动物肉的区别） |
| `strTools` | string | 合成需要的工具（格式：`数量x合成项ID`） |
| `strConsumed` | string | 合成会消耗的材料（格式：`数量x合成项ID`） |
| `strDestroyed` | string | 摧毁列表（实际用于熄灭火把） |
| `nTreasureID` | int | 合成产物的战利品池 |
| `fHours` | float | 消耗的行动点数 |
| `nReverse` | int | 是否可以逆向工程（衣服不能拆回，长/短线可以互拆） |
| `nHiddenID` | int | 是否是隐藏配方（只能通过摸索或纸片解锁） |
| `bIdentify` | bool | 是否能被鉴别 |
| `bTransferComponents` | bool | 未知 |
| `vAlsoTry` | string | 同类配方的其他 ID |
| `nTempTreasureID` | int | 合成时虚影显示的合成结果 |
| `bDegradeOutput` | bool | 合成品耐久是否与材料关联（1=关联，如长矛） |
| `strType` | string | 配方类型/名称 |

### 合成原理

合成系统通过三个表联动：
1. `recipes` 定义需要哪些合成项
2. `ingredients` 定义合成项需要哪些属性
3. `itemprops` 为物品赋予属性

**示例（烤小块肉）**：
- 配方 `strTools` 引用合成项 7, 17, 9
- 合成项 7 需要属性 "热源"（11）
- 合成项 17 需要属性 "杆状物"+"固体"（13,28）
- 合成项 9 需要属性 "杆状物"+"小的"+"有营养的"+"生的"（13,15,14,66）
- 满足属性的物品（如大火堆+木棍+小肉条）即可合成

### 从零创建新合成

1. 创建新的战利品池
2. 创建新的合成项属性
3. 创建新物品并赋予新属性
4. 创建新合成项并赋予新属性
5. 创建新合成方式，加入合成项和战利品池

## 24. 战利品池 (treasuretable)

定义物品生成/掉落的内容。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 代码标号 |
| `strName` | string | 战利品池名称 |
| `aTreasures` | string | 战利品内容 |
| `bNested` | bool | 生成物品是否会装在同时生成的容器里 |
| `bSuppress` | bool | 抑制内容物生成（如设 1，生成枪时不带子弹） |
| `bIdentify` | bool | 生成物品是否被辨识（是否显示隐藏名称） |

### 掉落格式 (aTreasures)

格式：`物品IDx数量x概率`

- `87.1x1.0x1` = 100% 几率生成 1 个 ID 87.1 的物品
- `99.9x2.0x0.5` = 50% 几率生成 2 个 ID 99.9 的物品
- 多个掉落用逗号分隔
