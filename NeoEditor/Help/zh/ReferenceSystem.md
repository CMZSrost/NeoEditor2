# 引用系统指南

NeoEditor 的引用系统用于处理游戏实体之间的关联关系。例如：配方引用材料、生物引用攻击方式、物品引用属性等。

---

## 引用字段的识别

在 DataGrid 中，引用字段以 **青色（Teal）下划线** 显示，而非引用字段为普通黑色文本。

---

## 单值引用

单值引用存储一个目标 ID。例如：
- `Creature.Faction` → 引用一个 `Faction` 实体
- `ItemType.nTreasureID` → 引用一个 `TreasureTable` 实体

### 操作

| 操作 | 效果 |
|------|------|
| **悬停** | 显示目标的类型和名称 |
| **Ctrl+悬停** | 显示 `TypeName: Subject (id=X)` |
| **Ctrl+Click** | 在右侧 **Ref Inspect** 面板预览目标 |
| **双击** | 直接跳转到目标实体所在标签页 |
| **右键 → 跳转** | 跳转到目标实体 |

---

## 多值引用

多值引用包含多个目标 ID，用分隔符（`,` 或 `+` 或 `&` 或 `|`）连接。例如：
- `ItemType.vProperties` → `16,46,48`（引用多个 ItemProp）
- `Recipe.strTools` → `1x2+1x3`（引用 Ingredient 并带数量）

### 多值引用的 Pattern 格式

| Pattern | 示例 | 说明 |
|---------|------|------|
| `{id}` | `152` | 纯 ID |
| `{id}x{mult}` | `55x0.75` | ID + 倍率 |
| `{mult}x{id}` | `1x2` | 数量 + ID |
| `{id}={value}` | `22=0` | ID + 值（装备槽位） |

### 操作

- **悬停**：显示每个子项的名称
- **Ctrl+Click**：点击单个子项 → 预览目标
- **右键 → 跳转到**：展开所有子项列表，选择跳转

---

## 反向引用

右键行 → **Find references to this...** 可以查找哪些实体引用了当前行。弹窗显示所有引用者的表名和字段名。

---

## Ref Inspect 面板

右侧面板的 **Ref Inspect** 标签页用于预览引用的目标实体：

- **Pin**：锁定当前预览，后续 Ctrl+Click 不会更新面板
- **Open Full**：跳转到目标实体的完整编辑视图
- **◀ ◀**：浏览预览历史（后退/前进）

---

## 合并视图中的引用

合并视图中，引用会根据覆盖链自动选择正确的目标：
- **命名空间匹配优先**：如果 ID 包含命名空间前缀（如 `NSE:42`），优先匹配同名空间实体
- **ModId 优先**：同一 ID 存在多个 Mod 版本时，选择最高 ModId（覆盖链胜者）
- **被覆盖实体的引用**：跳转目标自动指向胜者版本，悬停 ToolTip 显示来源
