# 欢迎使用 NeoEditor

NeoEditor 是一款为 **Neo Scavenger** 设计的 Mod 编辑器。它提供了可视化的数据表格编辑、引用导航、合并视图和多格式导出功能。

---

## 功能概览

| 功能 | 说明 |
|------|------|
| 📝 **DataGrid 编辑** | 24 种游戏数据类型的表格编辑，支持增删改查 |
| 🔗 **引用系统** | 实体间的引用关系自动高亮、预览和跳转 |
| 🔀 **合并视图** | 多 Mod 数据叠加合并，覆盖链追踪 |
| 📦 **导入导出** | CSV/XLSX/Markdown/JSON 多格式导出 |
| 🎨 **可视化编辑器** | 配方树、剧情流程图、战利品树、物品穿戴预览 |
| 🔍 **全局搜索** | 跨所有实体类型的全文搜索 |

![NeoEditor 界面](./neoeditor-help-demo.svg)

---

## 快速开始

1. **设置游戏目录**：点击左侧 ⚙️ Settings → 设置 Neo Scavenger 游戏根目录
2. **导入 Mod**：点击 📥 Import 或拖拽 Mod 文件夹到窗口
3. **编辑数据**：双击单元格进入编辑，右键引用字段可跳转
4. **保存**：`Ctrl+S` 保存到数据库和 XML

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+F` | 查找 |
| `Ctrl+H` | 替换 |
| `Ctrl+Click` | 预览引用 |
