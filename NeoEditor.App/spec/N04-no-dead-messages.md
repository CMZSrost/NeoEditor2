# [N04] 禁止死消息与多接收方歧义

| 字段 | 内容 |
|------|------|
| **是否启用** | ✅ 生效 |
| **类型** | 禁止(DON'T) |
| **创建来源** | 决策 D5 / 2026-06-29 代码审查 |
| **创建时间** | 2026-06-29 |

**是什么**
> 不得保留无接收方的消息（如 `FontSizeChangedMessage`、`ColumnVisibilityChangedMessage`、
> `GridRowHeightChangedMessage`）。不得用消息传递数据/读状态。同一消息不应有职责不清的
> 多接收方。

**为什么**
> 死消息和多接收方让消息系统不可审计、行为难追踪。配置类变更应走注入服务（如
> `IConfigService`）而非广播。

**决策边界**
> 适用：所有消息类型定义与收发。
> 处置：死消息删除或改为注入服务调用；多接收方需在 [R05](R05-messages-ui-only.md) 准则下说明理由。
> 相关：[R05](R05-messages-ui-only.md) 正面准则。
