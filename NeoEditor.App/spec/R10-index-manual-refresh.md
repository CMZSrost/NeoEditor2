# [R10] 索引手动刷新，编辑后标过期不自动重建

| 字段 | 内容 |
|------|------|
| **是否启用** | ✅ 生效 |
| **类型** | 基石(DO) |
| **创建来源** | open-questions Q2 / 2026-06-29 用户确认 |
| **创建时间** | 2026-06-29 |

**是什么**
> 正/反向索引初始为空，只在用户点刷新时构建。编辑实体后，索引标记「已过期」角标，
> 但**不自动重建**，仍需用户手动点刷新。

**为什么**
> 索引构建开销大，跟随选中/编辑自动重建会卡顿。手动刷新 + 过期角标兼顾性能与可感知性：
> 用户知道数据变了、需要时再刷。

**决策边界**
> 适用：Bottom 的 Ref Index / Reverse Index 两表。
> 不适用：DataTable 主表（随数据加载，不属于索引）。
> 相关：[R01](R01-state-single-owner.md) 索引归 Session 持有。
