# [R06] 四区域数据同源

| 字段 | 内容 |
|------|------|
| **是否启用** | ✅ 生效 |
| **类型** | 基石(DO) |
| **创建来源** | 决策 D6 / 2026-06-29 |
| **创建时间** | 2026-06-29 |

**是什么**
> Center 文档、Left KV 编辑器、Bottom DataTable 选中行，三者绑定**同一个 `IEntity`
> 实例**。一处修改通过 `INotifyPropertyChanged` 广播，各区域自动刷新。

**为什么**
> 各区域若各持实体副本，会出现「改了一处别处不更新」的不一致。同源同实例从根上消除
> 数据不同步，无需手动同步代码。

**决策边界**
> 适用：当前焦点实体在多区域的展示与编辑。
> 不适用：Peek 面板（只读预览，可显示另一目标实体，不要求同源）。
> 相关：[R08](R08-edit-entry-points.md) 限定编辑入口为 KV 与 XML。
