# [R14] 分层用文件夹+命名空间约定，不拆程序集

| 字段 | 内容 |
|------|------|
| **是否启用** | ✅ 生效 |
| **类型** | 基石(DO) |
| **创建来源** | open-questions Q6 / 2026-06-29 用户确认 |
| **创建时间** | 2026-06-29 |

**是什么**
> [R07](R07-one-way-layering.md) 的单向分层先用文件夹 + 命名空间约定落地，配合代码审查/lint
> 把关依赖方向，**不拆成多个 .csproj 程序集**。

**为什么**
> 单程序集改动小、迁移成本低，当前阶段足以约束依赖方向。拆程序集（编译期强制）工作量大，
> 留待结构稳定后视需要再上。

**决策边界**
> 适用：当前重构阶段的物理组织。
> 不适用：若约定屡被突破，再升级为多程序集强制（新建规则）。
> 相关：[R07](R07-one-way-layering.md) 分层方向；[R13](R13-vishelper-internal.md) internal 可见性依赖单程序集前提。
