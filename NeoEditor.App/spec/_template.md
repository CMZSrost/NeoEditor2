# 规则模板

> 复制本文件新增规则。命名：基石规则 `R0X-简述.md`，禁止规则 `N0X-简述.md`。
> 一文件一规则。新增是增量，不修改已生效规则的语义（要改则新建一条并把旧条置为「废弃」）。

---

# [R0X / N0X] 规则标题

| 字段 | 内容 |
|------|------|
| **是否启用** | ✅ 生效 / ⏳ 草案 / ⛔ 废弃 |
| **类型** | 基石(DO) / 禁止(DON'T) |
| **创建来源** | 决策编号 / 会话 / 代码审查 等 |
| **创建时间** | YYYY-MM-DD |

**是什么**
> 一句话说清规则内容。

**为什么**
> 这条规则解决什么问题、不遵守的后果。

**决策边界**
> 适用到哪、不适用到哪、例外情形、与哪条规则相关。
