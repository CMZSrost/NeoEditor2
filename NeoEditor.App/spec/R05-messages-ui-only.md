# [R05] 消息只做跨区域 UI 联动

| 字段 | 内容 |
|------|------|
| **是否启用** | ✅ 生效 |
| **类型** | 基石(DO) |
| **创建来源** | 决策 D5 / 2026-06-29 代码审查 |
| **创建时间** | 2026-06-29 |

**是什么**
> 消息（IMessenger）只用于跨区域 UI 联动（开标签页、切 KV 焦点、刷新覆盖链）。
> 读数据 / 读状态一律用注入服务直调。每条消息有单一明确的接收方。

**为什么**
> `DocumentWorkspaceViewModel` 注册了 15 种消息，`EntitySelectedMessage` 有 4 个发送方，
> 还有 `FontSizeChangedMessage` 等无接收方的死消息。消息既当事件又当数据通道，所有权扩散，
> 难以追踪。明确边界后消息系统可审计。

**决策边界**
> 适用：所有 `IMessenger` 的 Send/Register。
> 准则：联动→消息；取数→注入服务。多发送方允许，多接收方需明确理由。
> 相关：统一发送入口见 open-questions Q4；[N04](N04-no-dead-messages.md) 禁止死消息。
