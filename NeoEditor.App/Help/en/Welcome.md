# Welcome to NeoEditor

NeoEditor is a mod editor for **Neo Scavenger**. It provides visual data grid editing, reference navigation, merge view, and multi-format export — no manual XML editing required.

---

## Features

| Feature | Description |
|------|------|
| ⚡ DataGrid Editing | Spreadsheet-style editing for 24 game data types |
| 🔗 Reference System | Auto-highlight, preview, and jump between related entities |
| 🔀 Merge View | Multi-mod overlay merging with chain tracking |
| 📦 Export | CSV / XLSX / Markdown / JSON export |
| 🎨 Visual Editors | Recipe tree, story graph, treasure tree, item preview |
| 🔍 Global Search | Full-text search across all entity types |

---

## Quick Start

1. Set game root directory in ⚙️ Settings
2. Import a mod via 📥 Import or drag & drop
3. Edit data in the DataGrid tabs
4. Save with `Ctrl+S`
5. Export from ModDatabase right-click menu

---

| Shortcut | Action |
