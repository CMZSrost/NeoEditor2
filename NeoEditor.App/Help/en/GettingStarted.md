# Getting Started

## 1. Initial Setup

First set the **Game Root Directory** to your Neo Scavenger installation:

1. Click ⚙️ **Settings** (left sidebar)
2. Set the path to your game directory
3. e.g.: `D:\Steam\steamapps\common\Neo Scavenger`

---

## 2. Importing Mods

- **Drag & drop** a Mod folder onto the editor window
- Click 📥 **Import** in the toolbar
- Click **Import Mod** on the Home page

---

## 3. Opening a Mod

In the **🗄️ Mod Database** panel:
- Right-click a Mod → **Show Data** to open the editor
- Each game data type gets its own tab (ItemType, Recipe, Creature, etc.)

---

## 4. Editing

- **Double-click** a cell to edit
- `bool` fields → CheckBox
- `Enum` fields → Dropdown
- Reference fields (teal underline) → dropdown or click to navigate

### Row Operations
- **+** toolbar button → Add new row
- **-** toolbar button → Delete selected row
- Right-click row → **Clone Row**

---

## 5. Saving

- `Ctrl+S` saves to database + XML
- Tabs show **●** marker when modified
- Closing a dirty tab prompts for confirmation

---

## 6. Exporting

Right-click a Mod in **🗄️ Mod Database** → choose export format:
- CSV / XLSX / Crafting Table / Item Encyclopedia / Treasure Table JSON
