# 合并视图指南

合并视图让你看到多个 Mod 叠加后的最终游戏数据，类似于游戏实际运行时的数据状态。

---

## 打开合并视图

有以下方式打开合并视图：

1. **主页** → Profiles 列表 → 双击 Profile
2. **侧栏 Profiles** → 右键 Profile → **Open Merge View**
3. **侧栏 Profiles** → 双击 Profile 列表项

---

## 核心概念

### 命名空间

Neo Scavenger 使用命名空间来隔离不同 Mod 的数据：

- **命名空间 0**：游戏基础数据，也是覆盖（Merge）命名空间
- **非 0 命名空间**（如 `NSE`、`NSEa`）：插入（Insert）命名空间，数据追加不覆盖

### Merge vs Insert

| 类型 | 行为 | 数据显示 |
|------|------|----------|
| **Merge**（`strModName=0`） | 同一 ID 覆盖基础数据 | 在默认视图中只显示最终胜者 |
| **Insert**（`strModName≠0`） | 追加新数据，不同命名空间永不覆盖 | 与基础数据合并显示 |

---

## 界面元素

### Show All 切换
- **关（默认）**：只显示胜者（覆盖链最终结果），被覆盖的数据隐藏
- **开**：显示所有数据，被覆盖的行以 **灰色背景** 标记

### →Id 列
合并自增 ID：
- Merge 空间的实体保持原始 ID
- Insert 空间的实体在 Merge 空间最大值之后顺序自增

### Mod 过滤下拉
工具栏的下拉框可以按 Mod 筛选显示的数据行。

---

## 左侧覆盖链面板

选中数据行时，左侧面板显示该实体的覆盖链：
- **Winner**：当前生效的版本
- **Loser**：被覆盖的版本（灰色）
- **字段贡献**：展开显示每个字段来自哪个 Mod

---

## 底部面板

### Conflicts（冲突）
两个不同的 Merge Mod 修改了同一实体的同一字段时产生冲突：
- 冲突字段以 **红色背景** 高亮
- 底部 Conflicts 标签页列出所有冲突
- 工具栏按钮以 **红色脉动** 提示冲突数量

### Validation（验证）
保存时自动验证改动过的实体，结果显示在底部 Validation 标签页。

---

## 保存

合并视图中 `Ctrl+S` 保存：
1. 有修改的数据写入数据库
2. 数据写回源 Mod 的 XML 文件

关闭合并视图时，有未保存修改会弹出确认提示。
