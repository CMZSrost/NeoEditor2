# 内置预览：在编辑器中直接运行游戏

NeoEditor 内置 **Ruffle Web**（WASM 版 Flash/AIR 模拟器）预览，无需安装任何额外程序。
在数据编辑视图（合并视图）工具栏点击「**内置预览**」按钮，即可在右侧 WebView 面板中
直接运行游戏 SWF（`NEOScavenger.swf`）。

> 旧版「用 Ruffle 启动」（外部 ruffle.exe 进程运行器，需要手动安装 Ruffle + 设置
> `RUFFLE_PATH`）已于 2026-08-05 移除，由内置预览取代。本页只描述当前方式。

---

## 1. 使用「内置预览」

1. 打开任一 Mod 的编辑视图（合并视图），确认工具栏有「内置预览」按钮（眼睛图标）。
2. 点击按钮 → 右侧 WebView 面板打开并加载游戏（首次会启动本地回环服务器，稍等片刻）。
3. 预览使用**编辑器当前状态**（实时反代）——未保存/未导出的改动也能直接看到，**无需先导出**。
4. 再次点击「内置预览」可重新加载；想退出预览关闭 WebView 面板即可。

> ⚠️ 预览中看到的 bug 可能是**尚未完成的编辑**导致的（所见即所编）。要验证正式效果，
> 请先「保存并导出」再用「保存并启动」（`NEOScavenger.exe`）运行。

## 2. 依赖

- 预览需要 `Web/ruffle` 资源（随发布包内置，无需安装任何东西）。
- 若点击后提示「Ruffle Web 资源未部署」，说明运行目录缺少 `Web/ruffle`——重新发布即可。
- 游戏根目录需存在 `NEOScavenger.swf`（找不到时按钮会提示）。

## 3. 独立播放器（NeoScavengerPlayer）

除编辑器内预览外，仓库还提供**独立播放器** `NeoEditor.Player`（发布产物
`NeoScavengerPlayer.exe`，见 `Docs/42-webview-ruffle-preview-plan.md`）：
- 独立窗口运行游戏（同样是 Ruffle Web + 本地回环服务器），适合不打开编辑器时游玩。
- 支持存档备份（`{gameRoot}/save_backup`，最近 5 份）、数据浏览/wiki 式详情等功能。
- **存档管理（菜单 → 存档管理）**：**无需重启游戏**——游戏尚未读取存档时（如刚进主菜单）
  备份/删除/恢复都立即生效；游戏已读取过存档后，删除/备份仍免重启（删除不会被内存副本
  复活），仅**恢复需要重启游戏**加载（Ruffle 把运行中的存档缓存在内存里，读档界面读的是
  内存副本——这是模拟器的硬限制）。
- 编辑器「保存并启动」仍是正式游玩/交付验证路径（先导出 XML 再拉起 `NEOScavenger.exe`）。

## 4. 常见问题

| 问题 | 处理 |
|------|------|
| 点「内置预览」无反应 | 确认在编辑视图（合并视图）工具栏；确认游戏根目录存在 `NEOScavenger.swf` |
| 提示「Ruffle Web 资源未部署」 | 运行目录缺 `Web/ruffle`，重新发布/拷贝资源 |
| 启动弹窗「缺少 WebView2 Runtime」 | 播放器依赖 WebView2 渲染游戏：点「打开安装页面」按官方链接安装后重启播放器 |
| 启动即闪退（鼠标转圈后无反应） | 查看 exe 旁 `logs/player-boot-*.log`（启动日志：启动里程碑 + 崩溃原因），反馈时一并提供；运行/游戏日志在 `logs/player-run-*.log`。**若连 boot 日志都没有**——进程死在启动最早期（系统组件缺失/未升级，或杀软拦截），先升级 Windows 系统再试 |
| 预览卡在加载百分比 | 主要是编辑器写出的模组数据存在问题（Steam 模组版已知卡 43%）；非 Ruffle/播放器兼容性限制（带模组也能正常加载），先保存导出后用正式启动验证 |
| 预览与正式运行效果不同 | 预览 = 编辑器当前状态（可能半成品）；正式运行 = 磁盘导出态，两者语义不同 |
| 存档在哪 | 预览/播放器存档在 WebView 本地存储（SharedObjects），与原版游戏存档分开，不会污染原存档 |

> 实现细节与开发计划见 `Docs/42-webview-ruffle-preview-plan.md`。
