# 游戏数据结构全字段参考

> 本文档基于 Neo Scavenger **原版 `data/*.xml` 全量实测**（phpMyAdmin dump 格式），并参考了 NSE 各 mod 数据交叉验证。
> 涵盖全部 24 种游戏数据类型、每个字段的类型、含义、示例值和实测取值。适用于 Mod 制作和 NeoEditor 编辑参考。

---

## 阅读指南

### 列说明

| 列 | 含义 |
|----|------|
| **字段** | XML 中的字段名（DB 列名） |
| **类型** | 数据类型：`int` 整数 / `float` 小数 / `bool` 布尔(0/1) / `string` 文本 |
| **含义** | 字段的用途与语义 |
| **示例值** | 原版数据中最常见的取值（按出现频率取前 4 个） |
| **实测值域** | 原版数据中实际出现过的全部取值（太长则截断并标注总种数） |

### 类型后缀 `(refs)` — 引用字段

类型带 `(refs)` 的字段是**引用字段**：它的值指向另一张表（或图片资源）的实体。编辑器中显示为可点击跳转的链接（青色下划线），双击可打开目标实体。

### 命名空间前缀

引用值中可以带命名空间前缀：

| 写法 | 含义 |
|------|------|
| `152` | 无前缀 → 引用**当前实体所在**命名空间（同 Mod 或原版） |
| `0:152` | 显式指向 **0 命名空间**（游戏原版数据） |
| `NSE:152` | 显式指向 **NSE 命名空间**（该 Mod 的数据） |

> 图片引用（`strIMG`/`strImg`/`vImageList`/`vSpriteList` 等）同样支持前缀，如 `0:AModeSpearSharp.png` 表示使用原版图片。

### 常用符号速查

- `-` 前缀：否定 / 移除（如 `aConditions=-126` 表示"必须没有状态 126"）
- `,` 分隔：AND 并列（全部生效）
- `|` 分隔：OR 分支（多选一）
- `x` 倍率/数量：`数量xID`（recipes 材料）或 `IDx倍率`（vAttackerConditions）
- `=`: 赋值或键值对（`槽位=状态`、`状态名=物品`）
- `[id,p1,p2]`：括号条件（BattleMove 状态组）
